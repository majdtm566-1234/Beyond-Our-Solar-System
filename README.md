# Beyond-Our-Solar-System
A beginner Python data-analysis project exploring confirmed exoplanet radii using NASA Exoplanet Archive data.
Planets Explorer: Beyond Our Solar System

About the Project

This is my first Python data-analysis project. I created it to explore exoplanets—planets that exist beyond our Solar System—and investigate how their sizes compare with Earth's.

Research Question

How many confirmed exoplanet records have radii between 0.8 and 1.2 times Earth's radius?

Data Source

NASA Exoplanet Archive: https://exoplanetarchive.ipac.caltech.edu/

What the Project Does

Retrieves exoplanet data from NASA's Exoplanet Archive.

Uses Python and pandas to organize and filter the data.

Identifies planets within a selected radius range.

Creates a histogram to visualize the distribution of planet sizes.

Exports the matching records to a CSV file.

Preliminary Results

In my initial run, the dataset contained 6,401 records with usable radius measurements. Of these, 419 had radii between 0.8 and 1.2 Earth radii.

These results describe the retrieved dataset and are not a count of every Earth-sized planet in the universe.

Limitations

A radius similar to Earth's does not mean a planet is habitable. Other factors, including atmospheric composition, temperature, and orbital conditions, must also be investigated.
